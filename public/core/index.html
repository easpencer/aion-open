Setup guide

What runs where — the complete picture

Four independent pieces. Use only what you need. Each works without the others.

Step 1
Your Phone
Required for everything

Download the Aion app from the App Store (iOS) or Play Store (Android). It runs the bridge server.

1. Open Settings → Bridge and tap Start 2. Note the 6-digit pairing code shown on screen (changes each session) 3. Note your phone's IP address shown below the code
WiFi mode: Phone and PC on the same network. Connect to wss://<phone-ip>:8420
USB mode (no network needed): In the bridge screen, switch to USB tab, then run on your PC:
iproxy 8420 8420 iOS (requires libimobiledevice)
adb forward tcp:8420 tcp:8420 Android (requires ADB)
Then connect to wss://localhost:8420
Step 2 (optional)
Bridge Server
REST API + browser console

Runs aion-open on your PC. Exposes your phone's FHIR data as a standard REST API at localhost:3000. Includes a browser console, CLI, and code generator.

Requires: Node.js 18+
# One-time setup git clone https://github.com/easpencer/aion-open cd aion-open && npm install # WiFi — replace with your phone's IP and pairing code BRIDGE_URL=wss://192.168.1.42:8420 PAIRING_CODE=123456 npm start # USB (iOS) — run iproxy first, then: iproxy 8420 8420 BRIDGE_URL=wss://localhost:8420 PAIRING_CODE=123456 npm start # USB (Android) — run adb forward first, then: adb forward tcp:8420 tcp:8420 BRIDGE_URL=wss://localhost:8420 PAIRING_CODE=123456 npm start

Then open http://localhost:3000 in any browser. No login, no cloud.

Step 3 (optional)
MCP Server
AI assistants ↔ your health data

Connects Claude Code, Cursor, Windsurf, Gemini CLI, Zed, and other MCP-compatible assistants directly to your phone's bridge. Gives your AI tools to query FHIR data, run analysis, and write observations back — live, from real data on your phone.

Requires: Node.js 18+. No bridge server needed — connects directly to your phone.

One command — auto-discovers your phone, tests the connection, and configures all installed AI clients at once:

npx aion-bridge-mcp setup

The setup wizard will:

1. Search for your phone on the local network (Bonjour + ARP + subnet scan) 2. Prompt for the 6-digit pairing code from Aion Settings → Bridge 3. Test the connection and save config 4. Detect every installed AI client and write configs automatically

Other commands:

# Fix a broken or stale config npx aion-bridge-mcp repair # Find your phone on the network npx aion-bridge-mcp discover # Export your health data as a FHIR bundle npx aion-bridge-mcp export --output health.json npx aion-bridge-mcp export --type Observation --output vitals.json

USB mode with MCP — run on your PC first, then use wss://localhost:8420:

# iOS iproxy 8420 8420 # Android adb forward tcp:8420 tcp:8420 # Then set in .mcp.json env "AION_BRIDGE_URL": "wss://localhost:8420"

Restart your AI assistant, then ask: “What are my BP trends?” or “What medications am I on?”

Step 4 (optional)
Desktop Companion
PC activity → health graph

A tray app for Mac/Windows. Captures computer activity and sends it to your health graph — anonymized, categories only, no content. Your graph discovers correlations like “BP higher on weeks with >6h meetings.”

✓ Screen time, meetings, breaks ✓ App categories (never specific names) ✓ Typing intensity: high / medium / low
✓ Correlates with BP, HRV, sleep, glucose ✓ Configures AI clients (MCP) in one click ✗ Never: URLs, app names, content, keystrokes
One-tap connect: In Aion → Settings → Bridge, tap Copy Connection String. This copies an aion:// URL that opens the desktop app and pre-fills the address and pairing code automatically.

REST API

Endpoints

All return JSON. Connect first, then query freely.

MethodEndpointDescription
GET/api/{type}Query FHIR resources. Params: category, limit, start, end
GET/api/{type}/{id}Get a single resource by ID
POST/api/analyzeAsk a health question. Body: {"question":"..."}
GET/api/_exportExport FHIR Bundle or CSV
GET/api/_metadataFHIR R4 CapabilityStatement
GET/api/_graphKnowledge graph: nodes, edges, communities, god nodes
GET/api/_graph/reportHEALTH_REPORT.md — structured summary for LLM context
GET/api/_auditView bridge audit log
POST/api/connectConnect to phone bridge
GET/api/statusConnection status
Code Examples

Build with any language

Standard HTTP. No SDK needed.

Python
import requests

resp = requests.get(
    "http://localhost:3000/api/Observation",
    params={"category": "vital-signs", "limit": 20}
)
for entry in resp.json().get("entry", []):
    r = entry["resource"]
    name = r.get("code", {}).get("text", "?")
    val = r.get("valueQuantity", {})
    print(f"  {name}: {val.get('value')} {val.get('unit', '')}")

# Ask your AI about your health
resp = requests.post(
    "http://localhost:3000/api/analyze",
    json={"question": "Summarize my recent vitals"}
)
print(resp.json().get("answer", ""))
JavaScript
const resp = await fetch(
  "http://localhost:3000/api/Observation?category=vital-signs"
);
const data = await resp.json();

for (const { resource } of data.entry || []) {
  console.log(
    `${resource.code?.text}: ${resource.valueQuantity?.value} ${resource.valueQuantity?.unit}`
  );
}

// Ask your AI about your health
const analysis = await fetch("http://localhost:3000/api/analyze", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ question: "Any concerns with my BP?" })
});
console.log((await analysis.json()).answer);
